# Web apps (for testing)

Standalone single-file web versions of the other learning apps. Each folder is
self-contained: open `index.html` in a browser, no build step.

| Folder | App | Topic |
|---|---|---|
| `fret-by-fret/` | Fret by Fret | Guitar theory, sheet music, pedals, MuseScore |
| `atlas/` | Atlas | Countries, capitals, cities, maps |
| `py-by-py/` | Py by Py | Python |
| `slide-by-slide/` | Slide by Slide | Advanced PowerPoint |
| `desk-skills/` | Desk Skills | Excel, Windows, Word, Outlook shortcuts |

Folder names and structure are provisional, pending decisions on naming and how
these fold into the main Mot à Mot app.
